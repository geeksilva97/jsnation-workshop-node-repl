# Understanding The Problem

## What do we have?

- the payload should be

```json
{
  "price_token": "WybUz1hP9SP1ZYmZy3EPSb8i",
  "payment_token": "4072a40d26ab1de87a9a4b4554e4a826646647702eab4263c5eeadd12364eedc",
  "start_at": "2025-06-18T00:00:00Z",
  "end_at": "2025-06-19T00:00:00Z",
  "amount": 20000
}
```

- we need to create a new endpoint `/reservation` that should create a reservation
- `price_token` comes from `http://localhost:3000/price`
- `payment_token` comes from 

```
curl -XPOST http://localhost:4000/payment-tokens -H 'Content-Type: application/json' -d '{"card_number": "4111111111111111", "cvv": "123", "expiration": "11/29"}'
```

## Retrictions

- Authentication is required
- The `price_token` must be validated against the **relevant** parameters payload
- Reservations are only allowed from today (inclusive) and three months ahead.
- call the Mock Payment API (`POST /payments`)
